# Supermart Sales Analysis

These are scripts and data used by analyzing sales information of grocery stores. The analysis consists of data cleaning, exploration, and other visualization proceeding with the usage of R and Python.

## Project Description
This project aims at considering the sales analysis data in the grocery store and extracting information to aid in bettering sales strategies. This includes:
- The identification of trends in the sales information.
- Visualizing sales trends
- Arriving at evidence-based suggestions.

## Dataset
The data set has the information concerning the sale in grocery stores, and the details are:
- Item categories
- Quantity sold
- Sales amounts
- Store locations

**File(s) in this repository**:
- `Supermart Grocery Sales - Retail Analytics Dataset.csv: The initial set of data with the sales data.
- Assignment 6.Rmd Assignment Rmarkdown script of data analysis and visualisations.
